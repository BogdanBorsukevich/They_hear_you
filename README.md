🌑 They Hear You
They Hear You — це невеликий survival horror проект, створений на базі Unreal Engine. Розроблено в рамках навчального процесу (КНУ) для демонстрації базових механік взаємодії, ШІ та роботи з інтерфейсом.

У цій грі гравцю необхідно досліджувати локацію, шукати ключові предмети, збирати сюжетні фрагменти та, найголовніше, — уникати зустрічі з монстром, використовуючи стелс.

✨ Ключові механіки
Система інвентарю: Динамічний інвентар для збору артефактів (5 шт.), ключів (3 шт.) та ліхтарика.

Штучний інтелект (AI): Монстр, що патрулює рівень та переслідує гравця, використовуючи NavMesh та кастомну систему KillZone.

Стелс-елементи: Можливість ховатися від монстра у шафах (Lockers).

Система взаємодії (Interaction System): Універсальний інтерфейс для підбирання предметів, відкриття дверей та читання підказок.

Сюжетні фрагменти: Система записок, розкиданих по рівню, які можна читати через окреме UI меню.

Динамічний UI: Підказки на екрані, меню інвентарю, екран смерті.

🎮 Керування
W A S D — Рух

E — Взаємодіяти / Підібрати предмет / Сховатися в шафу

Right click — Наблизити камеру (Zoom)

Spacebar — Стрибок

F — Увімкнути/Вимкнути ліхтарик

Left Ctrl — Присісти

I — Відкрити інвентар

Tab — Прочитати знайдений фрагмент тексту

🚀 Як пограти (Для одногрупників)
Оскільки це Unreal Engine проект, для запуску гри не потрібні додаткові програми, але важливо дотримуватись інструкції:

Перейдіть у розділ Releases (або завантажте ZIP-архів за посиланням).

Завантажте архів із грою.

⚠️ ОБОВ'ЯЗКОВО розпакуйте архів у будь-яку зручну папку на вашому ПК. (Не запускайте гру прямо з архіву, вона покаже чорний екран!)

Відкрийте розпаковану папку та запустіть файл They_hear_you.exe.
